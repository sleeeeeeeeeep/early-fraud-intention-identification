# V361-P1 固定滑窗聚合对照实验结果

## 1. 结论

- **Max 聚合胜出**：长文本 Dev 上，诈骗召回从 V341-D1 截断基线的 `65.0%` 提升到 `77.5%`（+12.5pp），13 类准确率从 `73.33%` 提升到 `81.25%`（+7.92pp），normal FPR 从 `10.83%` 降到 `3.33%`（-7.5pp）。
- **短文本零退化**：Dev-A2 1801 条全部为单窗口（`length_band=short`），13 类准确率 `92.28% → 92.34%`（+0.06pp），macro-F1 `92.55% → 92.61%`，normal FPR `17.12% → 15.75%`。三种聚合在单窗口下数值完全一致，符合“单 chunk 必须与 V341 一致”的设计要求。
- **全量覆盖已达成**：所有子任务 `coverage_min = 1.0`，长文本没有任何 token 被静默截断。
- **Q4 后置证据仍是短板**：Max 在证据落在最后四分位的样本上召回仅 `56.67%`，明显低于 Q1 的 `93.33%`，是下一阶段（路线 A/B 可学习聚合）要解决的重点。

## 6. 本次为跑通而修复的问题

| 问题 | 根因 | 处理 |
|---|---|---|
| 远端 Gitee 下载卡死 | 实验机无外网 | 改用 SSH 逐文件直传 + SHA-256 校验 |
| `ModuleNotFoundError: fraudce_agent` | 启动器 PYTHONPATH 只含 `src/v361` | 补入项目根与 `scripts/cascade` |
| `ModuleNotFoundError: training.longdoc_losses` | 远端存在同名常规包，压过无 `__init__.py` 的命名空间目录 | 把 `data`/`models`/`training` 的 `__init__.py` 纳入 stage |
| `TypeError: dict | dict` | 远端 Python 3.8 不支持 3.9 的字典合并语法 | 改为 `{**a, **b}`（collator 与 train_longdoc 两处） |
| 4 张卡编排 | 需要限制在 2 张卡 | runner 改为按 GPU 分组串行队列，并限制最多 2 张卡 |
